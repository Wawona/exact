# Windows host (SwiftVM ARM64)

## Rough

- In-tree Caltrain authors its own workspace, so `bringPlatform` names
  `host.windows` but does not generate `.exact/shells`. Needed an authored
  `apps/caltrain/windows` crate (Rust data, not the TypeScript shell template).
- `ring` on `aarch64-pc-windows-msvc` needs `clang` on PATH. VS Build Tools'
  Llvm folder only had format/tidy; extracted LLVM 23.1.5 WOA64 via
  `msiexec /a` into `%USERPROFILE%\LLVM`.
- A private `CARGO_TARGET_DIR` outside the checkout broke bake provenance
  (`compiler input has no captured source identity` for `caltrain_gpu.dll`).
  `scripts/app.mjs` `nameOf` now accepts `app.target`.

## Lean in

`bun host/windows/build.mjs caltrain` with `EXACT_PAINTER=cpu` /
`host.windows.painter: "cpu"`. Agent: `tree` / `state` / `screenshot` against
`dist-windows/Caltrain.exe`.

## Checkpoints

- Built `Caltrain.exe` (~31 MB) + `caltrain_gpu.dll` on Windows 11 ARM64.
- Opened on the console desktop (`--run` via scheduled task); first present
  ~3.3 s.
